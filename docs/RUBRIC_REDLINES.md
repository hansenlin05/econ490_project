# 11/18 rubric — hard rules and red lines

Last updated 16 November 2026. This page dissects every clause of
`Econometric Files for Final Paper.pdf` (100 points, due 18 November 2026)
into two lists: what the submission **must** do, and what it **must not** do.
It is the technical compliance line for the files, not a statement of research
direction: teams are free to explore any specification they can defend, but
the submitted files must satisfy every rule below.

Method: each rule is tied to the rubric item and point value it comes from. If
a rule and a preferred-looking shortcut conflict, the rubric wins.

---

## 1. The four absolute gates (failure loses points regardless of quality)

| # | Must do | Must NOT do | Source |
|---|---|---|---|
| G1 | Upload to Canvas one set of **do / log / data / image** files; Canvas accepts only `log, csv, png, do, docx, jpeg` | Upload `.xlsx` or `.dta` (try the Excel summary table first; if Canvas rejects it, upload the `.csv` fallback); submit from GitHub instead of OneDrive | Assignment header; Course Outline p.14 |
| G2 | Keep the log **well organized, fully annotated, ≤35 pages** (instructor confirmed 35 on 16 Nov 2026; the printed rubric still says 25); if longer, tidy the do-file | Merge the four numbered logs into one or leave a log ungenerated by its do-file | Rubric "Log File" 15 pts; instructor confirmation |
| G3 | Have your log produced by your do-file; every number in the paper must be traceable to a log | Hand-edit a log, table or figure; quote a number found only in a summary | Final Paper Checklist "Stata Files" gates; Course Outline |
| G4 | State in the Canvas comments **whether or not** the results support the hypothesis, and explain observations that did not merge | Claim the result must be significant, or leave unmatched-merge rows unexplained | Rubric "Hypothesis" 5 pts; "Merge" 8 pts |

**Why these are gates:** each is a standalone scored item or an explicit
submission condition. A statistically excellent project that misses G1–G4
loses 15–35 points before the regressions are read.

## 2. The ten required items, clause by clause

### Item 1 — Merge and citation (rubric: Merge 8 + Citation 4 = 12 pts)

- **Must**: perform every merge inside a do-file; cite **all** data sets in the
  do-file annotations; fix country names and year mismatches before merging;
  explain in Canvas comments any variable that still does not merge.
- **Must not**: merge outside Stata; list a source in the paper but not in the
  do-file; silently drop mismatched country-years without a comment.
- **Extension of the rule**: "explain any observations that did not merge"
  covers two distinct losses — rows that never matched, and matched rows lost
  later to lags or missing covariates. Both are explained in the Canvas draft
  in `SUBMISSION_STATUS.md` §3.

### Item 2 — Single-year summary table (3 pts)

- **Must**: report mean, sd, min, max and **N** for every variable, for **one
  representative year**, including **only rows where the main explanatory
  variable is non-missing**; use meaningful variable names; deliver as Excel
  **or** Word.
- **Must not**: report all years; compute one N for the whole table when the
  main regressor covers fewer rows (our 2019 table has 23 rows on the main
  regressor but only 20 on maternity/parental leave spending — the per-variable
  `count` columns make that visible).

### Item 3 — Graphs (7 pts)

- **Must**: publication-quality, titled, axes labelled, units and sources
  noted; upload as PNG.
- **Must not**: paste raw Stata output as a figure; leave default Stata titles.

### Item 4 — Diagnostic tests (2 + 2 + 3 = 7 pts)

- **Must**: test heteroskedasticity, serial correlation, and the need for year
  and panel fixed effects. Our log shows `xttest3`, `xtserial`, `testparm
  i.year` and `testparm i.country_id` (the latter after the LSDV `regress`;
  it aborts after `xtreg, fe`).
- **Must not**: report a single specification with no diagnostics, or claim a
  correction without running the test that motivates it.

### Item 5 — Interaction / non-linearity (part of the model choice)

- **Must**: add an interaction or non-linear term **only** if it improves fit
  **and** is explained by economic theory.
- **Must not**: add a term just because it is significant; keep a term that
  fails both tests. Our quadratic spending term is assessed in the log
  (p = 0.8334) and excluded.

### Item 6 — One properly specified regression (10 pts)

- **Must**: run **a single** properly specified regression with all variables,
  including year and panel fixed effects, a convergence variable (lagged log
  real GDP per capita), and corrections for heteroskedasticity and serial
  correlation.
- **Must not**: present two specifications and call both "the main result";
  omit the convergence variable; leave serial correlation uncorrected.

### Item 7 — Winsorized repeat (5 pts)

- **Must**: rerun that same regression with **all** variables winsorized, and
  comment on whether this is the preferred specification.
- **Must not**: winsorize only two variables and call it "all"; skip the
  preferred-specification comment. Our repeat covers all six continuous model
  variables and the comment states the unwinsorized model is preferred.

### Item 8 — Build-up table (15 pts)

- **Must**: generate in Stata and export as Word; add one variable at a time,
  main explanatory variable **first**, interaction **second** (if any); show
  coefficients, standard errors, significance stars, N, and **whether year or
  country FE were included ("yes"/"no")**; edit the exported Word file
  afterwards (the assignment says so explicitly); do not print FE estimates.
- **Must not**: let the estimation sample change across columns (ours holds
  all five at 347); leave the FE yes/no rows out; hand-write the table outside
  Stata.

### Item 9 — Subset table (10 pts)

- **Must**: compare the all-country regression with subsets — two subsets means
  three columns — export as Word; choose subsets **dedicated by the economic
  theory that explains the hypothesis**. Our split (EU childcare-targets group
  vs other OECD members) follows the EU Barcelona targets and the 2022 Council
  Recommendation on ECEC.
- **Must not**: choose a subset after seeing which split gives significance;
  drop a required column because it is weak. Our "other OECD" column is kept
  with an explicit low-power warning.

### Item 10 — Overlapping histogram (6 pts)

- **Must**: show the distribution of the **main variable** when the data are
  subdivided; put at least **two histograms on one chart**; upload PNG.
- **Must not**: show only one histogram, or histogram a different variable from
  the main regressor.

## 4. The report-writing traps that cost marks after the files are accepted

- Export a table and **edit it afterwards** — the assignment says the Word
  file "will need to be edited". FE yes/no rows belong in the table body.
- Keep the denominator closed: 477 input rows = 23 countries x 2000-2024
  observed; 347 estimation rows; 309 + 38 = 347 in the subset table. Label
  each explicitly.
- Read the exported Excel summary table per variable: N differs across
  variables because coverage differs (23 on the main regressor, 20 on leave
  spending).
- Every claim in the 11 Dec paper must match the final Stata output; no number
  may exist only in a conversation or a slide.

## 5. How to use this page

Before any change to the submission files, check it against §1 and §2: if a
proposed edit breaks a "must" or does a "must not", it is out regardless of
how good the reasoning sounds. Research exploration is welcome in separate,
clearly labelled work; the submitted set must still pass every line here.
