=====================================================================
一、文件夹里是什么
=====================================================================

顶层 7 个子包 + 一份 START_HERE_Research_Context.txt（2026-10-21）：

    Data/                             6 个原始/中间数据文件
    OECD_TEST7_HANDOFF/               Test7 交接包（与工作区那份同源）
    OECD_TEST7_REPRO/                 Test7 本机复现（与工作区那份同源）
    Gender_Gap_Research_Handoff/      10/21 的欧洲研究，含 py/log/do/json
    stata_europe_simple(1)/           22 国 266 obs 的「简单回归版」
    stata_oecd/                       OECD 简单回归版
    stata_simple(2)/                  另一份 OECD 简单回归版

文件类型以 csv(144)、dta(45)、json(33)、log(29)、md(27)、do(22)、
py(21) 为主。绝大部分属于 10/21 之前的老方向：Europe_Parents_Employment
（Eurostat 家庭口径、266 country-years、23 国）、Paid_Leave_Gender_Wage_Gap
（旧 wage gap / 行业面板）、Europe_Care_Gender_Gaps（托育）。

START_HERE_Research_Context.txt 自己第 7–9 行就写明：
「No robust causal effect of leave on the current outcome has been
established in either direction」，并明确「Earlier proposed topics
concerned wage gaps and industry panels. Those are not the current
response or sample. Do not reuse earlier wage-gap coefficients,
industry claims, 26-country targets」。这与本项目 10/21 已作废的
结论一致，所以那个包里的系数一律不能复活。

二、真正还有用的（按价值排序）
=====================================================================

1. 数据源 URL、数据集编号与访问日期 —— 12/11 论文 bibliography 直接要用的。
   Final Paper Instructions 逐字要求「References to all data must be
   included in the bibliography with properly formatted citations」，
   Checklist 也要求「Data source references are included」。
   出处 A：Gender_Gap_Research_Handoff/.../Europe_Parents_Employment/
           deliverables/Data_Sources.json，逐条给了 provider、dataset、
           accessed_UTC、完整 API URL、population 口径。
   出处 B：顶层 START_HERE_Research_Context.txt 第 29–36 行，列了
           Eurostat lfst_hhacwnc / lfst_hheredch / lfst_hhacednc /
           ilc_caindformal，OECD PF2.5 工作簿与定义 PDF 的 URL，
           WDI NY.GDP.PCAP.KD、NY.GDP.MKTP.KD.ZG、SP.URB.TOTL.IN.ZS。
   注意：这些 URL 对应的是旧 266 obs 面板取数口径，引用时要核对是否
   与我们当前 295/477 面板的取数一致；不能直接照抄成我们的数据说明。

2. Data/SOCX2025-All-nat-cur.xlsx —— OECD 社会支出原始工作簿，
   是 leave_gdp（公共育儿假支出占 GDP）的上游来源。当前项目的
   oecd_policy_donor.dta 来自 Test7 包，若助教追问该变量的原始出处，
   这份可作溯源佐证。不必放进 11/18 提交包。

3. 各子包的 SHA256.json / verification.json —— 记录了「每个 do 与 log
   配一份校验和、写清样本与模型」的做法，这个习惯值得在 12/11 前照做；
   但里面的数值（input_n 267、estimation_n 266、22 国、beta/p 值）
   属于旧面板，与当前 295/477 链无关，不能引用。

4. stata_europe_simple(1)/.../README.md —— 明确写了欧洲样本与 ILO 样本
   的人群定义差异（「Neither is restricted to couple households; these
   European definitions differ from the ILO couple-with-child-under-six
   population in the OECD package」）。这句话对论文 Data Section 解释
   两套样本口径不同很有用，且与我们已核实的一致。

三、不要用、也不要混进提交包的
=====================================================================

- 全部旧 do / log / py / 系数（22 份 do、29 份 log、21 份 py）：不同样本、
  不同政策定义（Total_Father_specific vs 我们的 PF2.1 paid weeks）、
  不同结果变量口径，且 10/21 已作废。
- stata_europe_simple(1)/.../reference/oecd_leave_history_source.xlsx：
  md5 = ffa8b040… ，而项目 data_raw/oecd_leave_history.xlsx 是
  f412b223…，**不是同一个文件**（那份对应 PF2.5 快照与 267 obs 面板）。
  绝对不要拿它替换项目里的工作簿，否则锁定面板会变。
- raw/*.json（Eurostat 原始 JSON）：注释里提到的「JSON 原件」确实在这里，
  但它属于旧 266 obs 口径，不是当前 eurostat_employment_raw.csv 的来源，
  不能当作当前链的 provenance 补件。
- __MACOSX/ 下的 ._ 开头文件：macOS 资源叉垃圾，无内容。

=====================================================================
四、结论
=====================================================================

11/18 交付所需的 6 个 data_raw 源文件已全部在 OneDrive 项目里，且
2026-11-13 已用项目副本做过字节级复现验证（两个锁定面板 CSV md5 与
正式版完全相同）。所以这个文件夹对 11/18 的价值是「溯源参考」，不是
「补件来源」；不要往 data_raw 里复制任何东西。

12/11 论文阶段建议只取：Data_Sources.json 与 START_HERE 第 29–36 行的
数据集 URL/编号、SOCX 工作簿的出处、以及 README 里那句样本人群定义差异。
取用前按 AER / Chicago Author-Date 改写成正式引用，并核对取数口径。
