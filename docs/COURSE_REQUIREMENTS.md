## 2. Explicit rules for the 18 Nov drop

From `Econometric Files for Final Paper.pdf`, pages 1-4.

**Header:** "File Types log, csv, png, do, docx, and jpeg". `.xlsx` and `.dta`
are **not** accepted. Export the summary table as `.csv` and/or `.docx`; upload
data as `.csv`; keep `.dta` for local reproduction only.

**Log:** "well organized, fully annotated and no longer than 25 pages" (15 pts).
If longer, "return your do file and tidy it up". Our four numbered logs are
about 14.7 / 7.3 / 17.9 / 22.6 pages under conservative 80-character wrapping,
each generated by its own do-file. If a grader ever demands a single merged
log, the chain must be shortened first: merged it would be roughly 62 pages.

**Ten required items:**

1. Merge the collected data in the do-file, **with a citation for all data in
   the do-file**; fix country names and year mismatches; explain any unmatched
   variables in the Canvas comments.
2. A table of mean, sd, min, max and N for all variables for **one
   representative year**, including **only observations that have the main
   explanatory variable**; meaningful variable names.
3. Properly formatted, publication-quality graphs with titles and labelled axes.
4. All appropriate tests: heteroskedasticity, serial correlation, year and
   panel fixed effects.
5. Consider an interaction / non-linearity term, **only** if it improves fit and
   has an economic-theory explanation.
6. A single properly specified regression with all variables, correcting the
   issues found above.
7. Repeat that regression with all variables winsorized, and comment on whether
   it is preferred.
8. A formatted table of a series of regressions with **one variable added at a
   time**, main explanatory variable first, interaction second if used; export
   as a Word document; do not show time/panel FE estimates. The table must show
   coefficients, standard errors, significance stars, N, and **whether year or
   country FE were included ("yes" or "no")**. The assignment says explicitly:
   "Note that this file will need to be edited after it has been exported."
9. A table comparing **subsets of countries** with the all-countries
   regression: two subsets means three columns; the team chooses the subsets;
   export as Word.
10. A histogram of the main variable when the data are subdivided, with at
    least **two overlapping histograms on one chart**, uploaded as PNG.

**100-point rubric (pages 3-4):** Canvas comments on whether results support the
hypothesis 5; log file 15; all datasets properly cited in the annotations 4;
merge in do-file plus Canvas comment on unmatched observations 8; variable names
5; heteroskedasticity test 2; serial-correlation test 2; time/panel FE tests 3;
single properly specified regression (year + panel FE, convergence variable,
corrected heteroskedasticity and serial correlation) 10; complete regression
table built one variable at a time (15, must be generated in Stata, exported as
Word, use the winsorized version if preferred); subset table 10 (**"The choice
of subsets must be a reasonable one that is dedicated by the economic theory
that explains the hypothesis"**); overlapping histogram PNG 6; single-year
summary table as Excel or Word 3; winsorized repeat plus a comment on whether it
is preferred 5; multiple publication-quality PNG graphs 7.

**Canvas comments** must state whether the results support the hypothesis (5
pts) and explain unmatched merge observations (part of the 8 merge points).
A ready-to-paste draft is in `docs/SUBMISSION_STATUS.md`.

## 3. Explicit rules for 11 Dec (source: `Final Paper Checklist_ ... .pdf`
and `Final Paper Instructions`)

- Stata Files gates, marked "REQUIRED, NO PAPER GRADED IF INCOMPLETE": log and
  do-files uploaded before the deadline; log created by the do-file; do-file
  fully annotated; all work reported in the paper included in do and log.
- At least eight peer-reviewed economics journal articles; AER-style
  bibliography; each cited paper must state its data source; empirical results
  cited with page numbers.
- Results section: equations, coefficients, SEs, significance, N, fixed
  effects, and the diagnostic/winsorization notes. No raw Stata output pasted
  into the paper.

`docs/LITERATURE_SOURCES.md` lists the ten article PDFs by filename.

## 4. Implicit rules (derived from the course's own Stata handouts)

Source files: `18 - Stata Workflow Guide – COMET.pdf`, the COMET notebooks,
Stata Test do-files (Test One-Seven), quiz do-files,
`StataCheatSheet_analysis_19.pdf`, and the lecture note
`Preparing for Panel Data Analysis`.

- **Only demonstrated commands.** The do-files may use only syntax literally
  shown in those handouts. `reghdfe`, `csdid`, `eventdd`, `bacondecomp` and
  similar commands from general Stata practice are out of bounds. Two local
  indexes record the permitted vocabulary:
  `docs/CODE_CONVENTIONS.md`, which lists the permitted command set and the
  material each command comes from.
- **Always cluster standard errors.** The lecture note gives a rough floor of
  30-50 clusters; 23 country clusters is below it, so inference is optimistic
  and PCSE is only a sensitivity check.
- **Workflow 18 structure** for the master and numbered do-files; `clear` in the
  master, never `clear all` in a sub-do-file; `capture noisily do` calls;
  §18.2.2 allows a separate do-file for tables.
- **Comment style**: one short `* ` line per block, describing only what the
  block does. No change logs, module numbers, dates, paper-writing hints or
  justifications of syntax. `display` is not part of the workflow.
- **The log must be reproducible from the inputs the team submits.** Hence
  frozen snapshots in `data_raw/` rather than live API calls. The course note
  `START_HERE_Research_Context.txt` also asks that the do-file rebuild logs,
  tables, figures and reported results.
- **Edit exported Word tables afterwards.** The assignment says so explicitly;
  in particular the "Year FE yes / Country FE yes" rows are expected as rows,
  while Stata's `etable` can only put them in a note without commands that are
  outside the permitted vocabulary. This is a manual step for the person doing
  the paper tables.
- **The project root holds only delivery directories.** No changelogs, no
  handover documents, no notes with non-ASCII filenames.
