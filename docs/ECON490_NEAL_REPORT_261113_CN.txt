三、为什么保留 Europe 主样本是必要的
=====================================================================

第一，课程上完全合规。Course Outline 逐字要求的是「demographic change
across OECD countries」和「OECD Family Database together with other
international sources」，没有规定必须用全 OECD 样本、也没有禁止在 OECD
国家内取欧洲子样本。我们 23 个欧洲国家全部是 OECD 成员，hypothesis.pdf
第一句就是「Among OECD countries...」。所以 Europe 不是跑题样本，而是
OECD 之内口径更一致的一个子面板。讲师「只做 OECD」的建议目前只有组内
转述，没见到书面原文，按课程公开文件不能当成硬性评分条款。

第二，删掉它的代价远大于收益。Step 2 锁定的假设、文献综述、变量字典、
11/18 已产出的描述统计表和图，全部建立在 23 国 2006–2019 上。删掉等于
把已完成且可复现的一半交付物作废，重写 Data、Literature Review 与 Results。
而 OECD extension 三列政策系数 p = 0.352 / 0.583 / 0.746，同样不支持 H1，
换过去拿不到任何显著性收益；它还因为 leave_gdp 缺失把估计样本砍到
333 / 333 / 443，26 个国家聚类仍低于课程讲义「a rough floor is 30–50」的
经验下限。

第三，识别上 Europe 更站得住。OECD 全样本含智利、哥伦比亚、日本、韩国等，
制度与劳动力市场差异远大于欧洲，TWFE 的平行趋势更难成立；欧洲 23 国制度
同质性更高，是现有 DiD 与事件研究相对可信的理由。

第四，两套分开报告正好满足 Checklist 的「All work reported in the paper
is included in the do and log file」：样本口径差异、缺失来源、稳健性都能
在 do 和 log 里逐条对上，是拿 Data 5 分和 Results 15 分的论据。

若讲师建议确实是书面硬要求，最低成本的做法是把主/次标签对调（只改论文
文字，不碰任何回归），而不是删样本；但目前建议维持现状，并在论文里明写
「OECD-wide extension as a robustness check」。

四、当前在符合课程标准下的回归结果
=====================================================================

所有回归都含滞后人均 GDP（Checklist 硬要求「Lagged GDP per capita is
included in all regressions」），控制变量 ${controls} = lag_lngdp、
lag_gdp_growth、leave_gdp；做了 year FE 检验（testparm）、异方差
（xttest3）、序列相关（xtserial）、Hausman、稳健与按国家聚类标准误、
AR1 PCSE、二次项与缩尾稳健性。所有表格用 etable 导出，论文里没有
Stata 直接输出。

Europe 主表六列 N = 272 / 272 / 272 / 295 / 272 / 295。核心变量
lag_fatherweeks10 的系数始终是 +0.668，显著性完全取决于标准误口径：

    未调整 FE          +0.668，SE 0.275，p = 0.016
    vce(robust)        +0.668，SE 0.329，p = 0.054
    vce(cluster 国家)  +0.668，SE 0.344，p = 0.065
    AR1 PCSE           +0.560，SE 0.207，p = 0.007

按知识库「Preparing for Panel Data Analysis」逐字要求「Always cluster
your SEs」，且讲义明说「The fix often changes significance more than any
change to the point estimate does」，课程口径下应以聚类结果为准，
即 p = 0.065，不显著。23 个聚类还低于讲义 30–50 的经验下限，所以这个
p 值本身偏乐观；PCSE 的 p = 0.007 只能作 sensitivity，且 COMET 15 明确
警告 Prais-Winsten 不自动控制固定效应（我们已显式写 i.year i.country_id
并做 testparm）。

    DiD 1.treated#1.post   −0.626，SE 1.376，p = 0.653，N = 295
    事件研究 k=−2 / 0 / +1 / +2  p = 0.878 / 0.815 / 0.817 / 0.603
    OECD extension 三列      +0.180 p=0.352、+0.148 p=0.583、+0.074 p=0.746
                             N = 333 / 333 / 443

表里其余显著项都是滞后人均 GDP、年份与国家虚拟变量，不是政策变量。

结论：论文应写「没有稳健显著的政策效应 / conditional association」，
而不是「政策有效」。这与 Research PDF 自己那句「rather than treating
statistical significance as proof of causality」正好接得上。原来出现过
的显著 p 值（Test7 交互项 p=0.002、GDP 修复前事件研究 k=+1 p=0.034）
分别来自未聚类标准误和滞后构造错误造成的样本选择，都已作废，不能
为了显著性回滚。

五、给 Neal 那边的三条落地建议
=====================================================================

一是不要按「OECD 交互项显著、欧洲不显著」去挑样本。那个显著来自 Test7
旧设定（20 国 77 obs、HIC 子样本而非欧洲），按国家聚类后交互项 p = 0.076
已不显著；在当前 TWFE 链上重做，Europe 掉到 69 个观测 p = 0.491，
OECD 掉到 78 个 p = 0.101，两边都不显著。weeks × pay_c 交互项不是
「多一个 control」，会改变主系数含义、触发非线性理论解释义务，主模型
不加。

二是不要为了星号改设定。课程上更正确的做法（聚类 SE、完整诊断、诚实
报告零结果）恰恰会削弱显著性；以拿到显著 p 值为目的回滚设定与 Checklist
和学术诚信冲突。
