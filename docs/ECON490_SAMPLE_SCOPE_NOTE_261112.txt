------------------------------------------------------------
一、简洁结论（中文）
------------------------------------------------------------

用 Europe 样本符合课程要求，综合使用 euro 与 OECD 两套样本是必要的，不建议删掉 euro。

Course Outline 原文是「examine the economic causes and consequences of demographic change across OECD countries」，Data 段写「The team research project draws on the OECD Family Database together with other international sources, including OECD.Stat and the World Bank DataBank」。课程要求的是「OECD 国家」与「OECD Family Database 为主、其他国际数据源可并用」，没有规定必须用全 OECD 样本，也没有禁止在 OECD 国家内取欧洲子样本。我们 23 个欧洲国家全部是 OECD 成员，hypothesis.pdf 第一句也是「Among OECD countries, the availability of father-specific paid parental leave...」，因此 Europe 不是跑题样本，而是 OECD 之内、口径更一致的一个子面板。讲师的建议应理解为数据源与主样本的偏好，不是评分清单里的硬性条款。

综合使用两套样本的必要性有三条。第一，Step 2 锁定的假设、Step 3 的文献综述、变量字典和 11/18 已产出的描述统计表与图，都建立在 Europe 23 国 2006–2019（N=295）上；删掉它等于把已完成且可复现的一半交付物作废，并重写 Data、Literature Review 与 Results。第二，OECD extension（26 国 2000–2024，N=477）虽然覆盖更长，但结果变量来自 ILO 家庭序列，与 Eurostat 口径不同，且 leave_gdp 缺失使三列估计 N 只有 333 / 333 / 443；其三个政策系数 p=0.352 / 0.583 / 0.746，同样不支持 H1，换过去不会带来任何显著性收益。第三，Final Paper Checklist 逐字要求「All work reported in the paper is included in the do and log file」，把 Europe 主样本与 OECD extension 分开报告（never pooled），正好把样本口径差异、缺失来源与稳健性写清楚，是拿 Results 15 分与 Data 5 分的论据，而不是负担。

建议的落地做法：保留现有 0_master → 1/2/3 链条与两套样本，不更动任何回归；在 Data 与 Limitations 里写明「primary Europe panel / OECD extension, never pooled」及其分母来源；若讲师的建议是明确的书面要求，再按组内决定把主次标签对调（OECD 标为主样本、Europe 标为一致性更好的敏感性样本），这比重写整篇代价小得多。在此之前不要删 euro，也不要为了显著结果换样本。

二、可发群里的英文短版
------------------------------------------------------------

Using the Europe panel is within the course requirements, and keeping both samples is worth doing. The Course Outline asks for "demographic change across OECD countries" and says the project "draws on the OECD Family Database together with other international sources"; it never requires the full OECD sample or forbids a European sub-panel. All 23 countries in our primary panel are OECD members, and our hypothesis is explicitly stated "Among OECD countries". Dropping Europe would void the hypothesis, the literature review, the variable dictionary and half of the 11/18 deliverables, while the OECD extension is no more significant (p = 0.352 / 0.583 / 0.746) and loses observations to missing leave_gdp (N = 333 / 333 / 443). Reporting the two panels separately, never pooled, is exactly what the Checklist means by having all reported work in the do and log files. If the instructor's preference is a formal written requirement, we can swap the primary/extension labels without touching any regression; until then, keep both and state the sample definitions in Data and Limitations.

五、补录（2026-11-13）：主次标签对调到底会改变什么
------------------------------------------------------------

问题：若把 OECD 标为主样本、Europe 标为 extension，对回归结果、研究方向、
现有进度各有什么影响。结论是「代码零改动、文字与论证要改、代价不小」。

（1）回归结果：一个数字都不变。
主次是论文与文档里的措辞，不是 Stata 设定。不改任何 do、任何 dta、任何系数。
Europe 主表六列 N = 272 / 272 / 272 / 295 / 272 / 295，OECD 三列
N = 333 / 333 / 443，所有系数、SE、p 值、诊断、图与表全部原样。
因此 **11/18 提交包零改动**：do / log / data / image / tables 一个字节不用动。
唯一会受影响的 Stata 产物是呈现顺序 —— 3_results_261109.do 里 europe 表在前、
oecd 表在后。若连顺序也要对调就得改 do 并刷新三份编号 log，为一句标签重跑
整链不划算，建议在 README 与论文里用文字说明顺序即可。

（2）研究方向：研究问题不变，但「主样本是谁」变了。
假设本身不用改：hypothesis.pdf 第一句「Among OECD countries」，两套样本都满足；
研究问题仍是父亲专属带薪假与男女就业差距。变的是 Abstract/Introduction 里
国家数与年份（23 国 2006–2019 → 26 国 2000–2024）、外部有效性宣称、以及
异质性讨论的落点。不变的是识别框架（国家+年份双向固定效应 + 滞后政策变量）。

三个实质代价必须写进组内决策：
    一、OECD 是更弱的主样本。leave_gdp 缺失把估计样本砍到 333 / 333 / 443，
        lag_fatherweeks10 首年缺失；26 个聚类仍低于课程讲义
        「a rough floor is 30–50」的经验下限；三列 p = 0.352 / 0.583 / 0.746
        同样不支持 H1。把最弱的一套放到论文中心，Results 15 分只会更难写。
    二、内部一致性。Research PDF 的假设推导、文献综述（欧洲 daddy quota 制度）、
        变量字典都围绕欧洲写。只换标签不改文字，会出现「主样本是全 OECD，
        但理论机制与文献全讲欧洲制度」的错位，评审会直接挑。
    三、识别假设。OECD 全样本含智利、哥伦比亚、日本、韩国等，制度与劳动力
        市场差异远大于欧洲，TWFE 的平行趋势更难成立；欧洲 23 国制度同质性
        更高，正是当前 DiD 与事件研究相对站得住的理由。

文献综述的结论落点。这些是 12/11 的工作，不影响 11/18。
