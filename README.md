## Research in one paragraph

The main panel uses ILOSTAT household employment data for 26 OECD countries,
2000–2024 (477 country-years before regression exclusions). The complete-case
main regression uses 333 country-years from 22 countries. It estimates the
conditional association between the employment gap and lagged father-specific
paid leave per ten weeks. Controls are lagged log real GDP per capita, lagged
GDP growth and public maternity and parental leave spending. The main model
uses country and year fixed effects with AR(1) PCSE. The leave coefficient is
+0.148 percentage points (p = 0.583). Country-clustered TWFE gives +0.180
(p = 0.352). Neither result supports the hypothesized gap reduction.

Further analyses report geographic subsets within the ILO panel and use the
separate Eurostat panel for European results, reform DiD and the event study.

## Reproduce

Set Stata's working directory to the project root and run
`do do_files/0_master_261109.do`. The root copies of the five do-files are
byte-identical to the `do_files/` copies; `do_files/` mirrors the folder
structure expected by `18 - Stata Workflow Guide – COMET.pdf`. The master calls
the four numbered do-files. Data construction and supplementary model fits run
first. The single submission log records merge counts, descriptives, the main
regression and diagnostics, and formatted tables for the supplementary fits.
`1_build_data` rebuilds both panels from the frozen files in `data_raw/`.

Requirements: Stata 17 or newer (developed on StataNow/SE 19), plus the
user-written `xttest3`, `xtserial` and `coefplot`.
Use `clear`, not `clear all`: the master defines globals that the numbered
do-files need.

**Inputs are frozen local snapshots.** A change that read five official
endpoints at run time was reverted (PR #1 / commit `8efda45`): ILOSTAT returned
HTTP 200 with 0 bytes for both `.csv` and `.csv.gz`, the Eurostat SDMX 3.0
response was 12.7 MB and unfinished after 20 s, and live source revisions
would make the submitted log irreproducible. Official sites are cited as
provenance only; access date for all five sources is **14 November 2026**.
